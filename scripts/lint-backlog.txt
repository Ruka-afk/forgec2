# Checked-in lint debt ceiling.
#
# This file pins the total finding count of a full uncapped golangci-lint run
# (.golangci.yml, all rules) per analysis target, so the gate does not depend
# on the host that ran the linter: CI records one JSON report with GOOS=windows
# (which includes the windows-only agent sources a native linux run would skip)
# and one with GOOS=linux, then scripts/check-lint-debt.sh compares both.
#
# The ceiling may only go DOWN. Pay debt down, refresh the numbers with
#   bash scripts/check-lint-debt.sh --update <windows.json> <linux.json>
# and commit the change together with the cleanup that paid it down.
# --update refuses to raise a number: growing the backlog is never the answer.
#
# The same JSON reports also enforce zero findings from the mechanical linters
# (unconvert, ineffassign, govet, misspell) on both targets.
#
# History: the windows target measured 1056 findings before the mechanical
# cleanup (2026-10). Excluding gosec G702 (its taint results flapped between
# identical runs — 5 of the 10 windows findings appeared or not) took windows
# to 967 and linux to 634, both stable across repeated warm/fresh runs.
#
# The windows ceiling carries one finding of headroom for the staticcheck
# issue that so far only appeared on the linux analysis host (CI measured one
# more than this machine); linux matches CI exactly. Tighten the windows
# number once a local run reproduces the CI count.
#
# Batch K (2026-10): dead-code adjudication paid the unused linter to zero on
# both targets (win 116 / lin 64 findings removed along with their write-only
# state), taking the whole-tree totals to 845 (win) and 569 (lin). The
# windows number again carries the +1 CI observation headroom.
#
# Batch L (2026-10): errcheck divide-and-conquer (Set*Deadline + LazyProc.Call
# config exclusions plus ~70 point fixes: session/config/crypto/plugin/
# scripting/delivery/PE-strip and the linux transport/relay/persistence set)
# and the staticcheck ST100 campaign (ST1003 renames incl. the dual-GOOS
# syscall-constant family, ST1005 error strings, ST1016 receivers, S10xx and
# SA9xxx small classes) took the totals to 361 (win) and 293 (lin). Remaining
# debt: errcheck typed-wrapper call sites (186/147), gosec G306-style mode
# findings, SA1019 deprecations (41/11 — syscall.Syscall6/grpc.DialContext/
# http2.Transport, deliberate keep), S1011/S1001 one-offs.
